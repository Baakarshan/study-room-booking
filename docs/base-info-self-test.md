# 基础信息域自测说明

1. 管理员依次新增校区、楼栋、楼层、自习室，确认列表和级联下拉正常。
2. 自习室设置 3 行 4 列并生成座位，确认得到 A01-A04、B01-B04、C01-C04 共 12 个座位。
3. 再次生成同一自习室座位，应提示“不能重复生成”；有座位时修改行列数也应拒绝。
4. 从校区向下逐级尝试删除，存在下级时均应拒绝；清空下级后允许删除。
5. 在座位页切换启用/停用，刷新后状态保持。
6. 输入非法开放时段、超过 26 行或 99 列、非法状态，后端应返回中文校验错误。

编译检查：`mvn -pl ruoyi-seatflow -am -DskipTests package`。
前端检查：在 `seatflow-ui` 执行 `npm run build:prod`。
